# AI Native — The Engineer’s Field Guide

Check out the **[tutorial online](https://rajarshi-personal.github.io/ai-native-in-application-and-sdlc/)**.

Open **[index.html](index.html)** in a modern browser. The tutorial is self-contained and works offline. No installation, API key, server, CDN, or external library is required.

For a rendered website on GitHub, publish the directory containing `index.html` with **GitHub Pages**. A normal repository file view shows the HTML source. Only `index.html` is needed to distribute or host the tutorial.

The guide includes:

- Twelve lessons covering AI-native products, architecture, RAG, agents, skills, MCP, loop engineering, UX, evaluations, specifications, operations, and policy.
- Eight guided labs, lesson recall questions, and an eight-scenario final assessment.
- A TrailCart e-commerce case study, from specifications and implementation tasks through release, duplicate-order repair, and retrieval incident response.
- Downloads for a project starter, team policy template, and personal readiness checklist.
- Light and dark themes, local progress, a saved specification scratchpad, a searchable glossary, reduced-motion support, mobile navigation, and print styling.

All demonstrations are deterministic local simulations. This is a teaching guide, not a running e-commerce backend or a live AI agent. Example thresholds and commands must be adapted and implemented in a real project. Primary-source links are included; visiting those external references requires internet access.

Progress and notes use browser-local storage when available. Storage behavior may vary when opening local files or using private browsing. Download important notes to keep a separate copy.

The `.verification/` directory contains development checks and screenshots; it is not required for the tutorial.
